Titanic:
Problem: Predict whether or not people would survive the titanic. I expected gender and age to be the main predictors of survival (women and children having a higher rate of survival)
Approach: In order to improve the models performance, I first filled NaN ages with random ages to ensure the NaN values would not affect the models predictions. I then added the engineered features IsAlone, Family size, and Age_Group as I thought these would be important indicators of survival that the current features couldn't fully capture. After that, I created 2 separate pipelines: one for categorical variables and one for numerical variables. I then combined these into a preprocessor, and created a final pipeline with the preprocessor and then logistic regression. Next I experimented with different penalties, values for C, and including and excluding features (I used C=10, no penalty, and all the features). Finally, I fit this model to the training data, adjusted the threshold, and submitted it to Kaggle.
Results: The CV score was 0.846, and the Kaggle submission score was 0.77751
Key Findings: The features that mattered most were age (specifically the age groups) and gender as I predicted, however passenger class and title had a surprisingly large affect on ones survival. Engineered features ended up being much more important than I would have expected
What I would try next: Using a random forest would be a fascinating way to approach this problem. Using a method that would tune the parameter of logistic regression C could also be useful as tuning that had a positive effect of the cross score. The most important addition that I would add would be feature regularization as the features had a wide variety of values and this could have had a noticeable impact on the outcome by reducing imbalance in the features, and possibly making penalties more viable.
