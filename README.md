# ML-2026

A self-directed machine learning project portfolio.

Building practical skills in data analysis, classical machine learning, deep learning, and reproducible ML workflows. This repository documents my notes, notebooks, mini-projects, experiments, and progress along the way.

## Main Topics

- Python, NumPy, pandas, and data visualization
- Linear and logistic regression
- Decision trees, random forests, XGBoost, and model evaluation
- Cross-validation, pipelines, feature engineering, and data-leakage prevention
- Neural networks, backpropagation, and optimization
- Reproducible project structure, experiment tracking, and technical documentation

## Examples of Projects

- Titanic exploratory data analysis and classification
- Ames house-price regression
- Telco customer-churn prediction with XGBoost
- Bike-sharing demand regression
- A final flagship machine learning project about weather prediction (work in progress)

## Goal

My goal is to move beyond following tutorials by building models from scratch, evaluating them honestly, documenting my decisions, and eventually creating a polished final project with a demo and technical write-up.
